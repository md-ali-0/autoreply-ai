# AutoReply AI 🦅

WhatsApp, Messenger, Telegram ও Instagram DM-এর জন্য AI-চালিত অটো-রিপ্লাই অ্যান্ড্রয়েড অ্যাপ।
ফোনে সব সময় ব্যাকগ্রাউন্ডে চলে — মেসেজ এলে AI নিজে উত্তর বানিয়ে পাঠিয়ে দেয়।

## কীভাবে কাজ করে

```
WhatsApp / Messenger / Telegram / Instagram নোটিফিকেশন
        │
        ▼
WhatsAppNotificationListener  ──►  ReplyEngine  ──►  AI (OpenAI-compatible)
   (sender + মেসেজ ধরে)            (নিয়ম যাচাই)              │
                                                             ▼
                        SendAccessibilityService  ◄──  রিপ্লাই টেক্সট
                        (চ্যাট খুলে Send চাপে)
```

- **Notification Listener** — নোটিফিকেশন থেকে প্রেরকের নাম, মেসেজ ও ফোন নাম্বার বের করে।
- **Reply Engine** — মাস্টার সুইচ, কোন অ্যাপ চালু, কন্টাক্ট ফিল্টার, সময়সীমা, কুলডাউন যাচাই করে AI-কে কল দেয়।
- **Voice Transcriber** — WhatsApp ভয়েস নোটের অডিও পড়ে টেক্সট বানায়, তারপর AI উত্তর দেয়।
- **Accessibility Service** — আসল চ্যাট অ্যাপ খুলে রিপ্লাই টাইপ করে Send চাপে।
- **Foreground Service + Boot Receiver** — ফোন রিস্টার্ট দিলেও নিজে থেকে চালু হয়।

### কোন অ্যাপে রিপ্লাই যায়

| অ্যাপ | প্যাকেজ | কীভাবে পাঠায় |
|---|---|---|
| WhatsApp | `com.whatsapp` | নোটিফিকেশনের inline reply, নইলে `wa.me` লিংক + Send ট্যাপ |
| WhatsApp Business | `com.whatsapp.w4b` | একই |
| Messenger | `com.facebook.orca` | নোটিফিকেশনের inline reply, নইলে content intent দিয়ে চ্যাট খুলে Send ট্যাপ |
| Messenger Lite | `com.facebook.mlite` | একই |
| Telegram / Telegram X | `org.telegram.messenger`, `org.thunderdog.challegram` | inline reply, নইলে content intent |
| Instagram | `com.instagram.android` | inline reply, নইলে content intent |

> WhatsApp ছাড়া বাকি অ্যাপে ফোন নাম্বারভিত্তিক ডিপ লিংক নেই — তাই ফলব্যাক পথে
> নোটিফিকেশনের নিজের content intent ব্যবহার করে ঠিক ওই চ্যাটটাই খোলা হয়।

> অফিসিয়াল WhatsApp API দিয়ে ব্যক্তিগত নাম্বারে অটো-রিপ্লাই সম্ভব নয়।
> তাই এখানে আসল চ্যাট অ্যাপটিকেই স্বয়ংক্রিয়ভাবে চালানো হয় — রুট লাগে না।

## সেটআপ (একবারই)

অ্যাপে ৫টা ট্যাব আছে — **অনুমতি · AI · কন্টাক্ট · টাইমিং · লগ**।
উপরে মাস্টার সুইচ (সব সময় দেখা যায়), নিচে সেভ বাটন।

**১. অনুমতি ট্যাব** — এই ৬টি চালু করুন:

| অনুমতি | কেন দরকার |
|---|---|
| নোটিফিকেশন অ্যাক্সেস | মেসেজ পড়তে |
| অ্যাক্সেসিবিলিটি সার্ভিস | রিপ্লাই পাঠাতে |
| কন্টাক্ট | নাম → নাম্বার ম্যাচ করতে (WhatsApp) |
| ব্যাটারি অপটিমাইজেশন বন্ধ | ব্যাকগ্রাউন্ডে বাঁচিয়ে রাখতে |
| অন্য অ্যাপের উপরে দেখানো | ব্যাকগ্রাউন্ড থেকে চ্যাট খুলতে |
| অডিও পড়ার অনুমতি | ভয়েস মেসেজ ট্রান্সক্রিপ্ট করতে — **"সব ফাইল পড়ার অনুমতি"** দিতে হবে (নিচে দেখুন) |

কতটা সম্পন্ন হয়েছে সেটা উপরে লেখা থাকে ("৩ / ৬ সম্পন্ন")।

> **ভয়েস মেসেজ পড়তে কেন "সব ফাইল" অনুমতি লাগে?**
> WhatsApp-এর ভয়েস নোট থাকে `Android/media/com.whatsapp/WhatsApp/Media/WhatsApp Voice Notes/`-এ,
> যেটা আরেকটা অ্যাপের প্রাইভেট ফোল্ডার আর তার ভেতরে `.nomedia` ফাইল আছে। তাই
> `READ_MEDIA_AUDIO` বা MediaStore কোনোটাই ওগুলো দেখতে পায় না — শুধু
> "All files access" (Settings → Apps → AutoReply AI → Special access) পারবে।
> এই রো-তে ট্যাপ করলে সোজা সেই সেটিংস স্ক্রিন খুলবে। অনুমতি না দিলে ভয়েস মেসেজ
> এলে অ্যাপ চুপ থাকবে (ভুল উত্তর দেবে না), আর লগে কারণ লেখা থাকবে।

নিচের **কোন অ্যাপে রিপ্লাই দেবে** কার্ডে WhatsApp, Messenger, Telegram আর Instagram
আলাদা করে চালু/বন্ধ করা যায়। সুইচ বন্ধ থাকলে ওই অ্যাপের মেসেজে কিছু পাঠানো হয় না।

**২. AI ট্যাব** — `API Base URL`, `API Key`, `Model` দিন।
যেকোনো OpenAI-compatible এন্ডপয়েন্ট চলবে (OpenAI, OpenRouter, Groq, DeepSeek, Together…)।
**AI টেস্ট করুন** চেপে যাচাই করুন। পারসোনা ফিল্ডে AI কীভাবে কথা বলবে লিখে দিতে পারেন।

নিচের কার্ডে তিনটি অতিরিক্ত সুইচ:

| সুইচ | কাজ |
|---|---|
| ভয়েস মেসেজ পড়ে উত্তর দেবে | ভয়েস নোট ট্রান্সক্রিপ্ট করে উত্তর দেয় (ট্রান্সক্রিপশন মডেল আলাদা করে দেওয়া যায়, ডিফল্ট `whisper-1`) |
| কন্টাক্টের ভাষায় উত্তর | ইংরেজিতে লিখলে ইংরেজিতে, বাংলায় লিখলে বাংলায় |
| পাঠানোর আগে অনুমোদন নেবে | AI নিজে পাঠায় না — নোটিফিকেশনে খসড়া দেখায়, "পাঠাও" চাপলে যায় |

**৩. কন্টাক্ট ট্যাব** — চাইলে "শুধু নির্বাচিত কন্টাক্ট" চালু করে নামের লিস্ট দিন (প্রতি লাইনে একটা)।
ডিফল্ট কান্ট্রি কোড `880` (বাংলাদেশ)।

**৪. টাইমিং ট্যাব** — শুধু অফিস আওয়ারে রিপ্লাই দিতে চাইলে সময়সীমা চালু করুন।
সাথে রিপ্লাইয়ের আগে অপেক্ষা, একই কন্টাক্টে কুলডাউন, ঐচ্ছিক সিগনেচার।

**৫.** উপরের **মাস্টার সুইচ** চালু করুন → **সেভ করুন**।

> ট্যাব বদলালে অ্যাপ নিজেই ওই ট্যাবের লেখা সেভ করে রাখে, তাই ভুলে গেলেও ডেটা হারাবে না।

## লগ ও ডাইজেস্ট

**লগ** ট্যাবে দেখা যাবে কোন মেসেজে কী রিপ্লাই গেল, কোথায় আটকালো।
সমস্যা হলে আগে এখানেই দেখুন।

**কী মিস করলাম?** বোতাম চেপে গতবারের পর থেকে আসা সব মেসেজের একটা সারসংক্ষেপ
দেখা যাবে — কতজন লিখেছে, কোনগুলো এখনো উত্তর পায়নি। নোটিফিকেশনেও আসবে।
AI সেট করা থাকলে সারসংক্ষেপটা AI বানায়, না থাকলে সাধারণ তালিকা দেখায়।

## বিল্ড

```bash
export JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'   # JDK 21
./gradlew assembleDebug
# → app/build/outputs/apk/debug/app-debug.apk
```

চাহিদা: Android SDK (platform 35, build-tools 35), JDK 17+, Gradle 8.14.3।

## সমস্যা হলে

| সমস্যা | কারণ |
|---|---|
| `নাম্বার পাওয়া যায়নি` | কন্টাক্ট পারমিশন নেই, বা কন্টাক্টে নাম্বার সেভ করা নেই (WhatsApp) |
| `Send বাটন পাওয়া যায়নি` | অ্যাক্সেসিবিলিটি সার্ভিস বন্ধ, বা অ্যাপের UI বদলেছে |
| `চ্যাট খোলার উপায় নেই` | নোটিফিকেশনে reply অ্যাকশন নেই, তাই চ্যাট খোলা যায়নি |
| `ভয়েস মেসেজ পড়া গেল না` | "সব ফাইল পড়ার অনুমতি" নেই, ফাইল পাওয়া যায়নি, বা প্রোভাইডারে `/audio/transcriptions` নেই |
| রিপ্লাই আসছে না | মাস্টার সুইচ বন্ধ / ওই অ্যাপের সুইচ বন্ধ / সময়সীমার বাইরে / কুলডাউনে / ফিল্টারে নেই / অনুমোদনের অপেক্ষায় — লগ দেখুন |
| ফোনে ব্যাকগ্রাউন্ডে বন্ধ হয়ে যায় | Xiaomi/Oppo/Vivo-তে "Autostart" চালু করুন + ব্যাটারি অনুমতি |

## গোপনীয়তা

API Key শুধু ফোনের নিজের `SharedPreferences`-এ থাকে। কোনো সার্ভারে কিছু যায় না —
শুধু AI প্রোভাইডারের এন্ডপয়েন্টে চ্যাট টেক্সট (আর ভয়েস নোট হলে অডিও ফাইল) যায়।
